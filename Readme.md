## Publier une photo depuis un smartphone

1. Ouvrir `https://jordan64-labs.github.io/Joclean/admin.html`.
2. Renseigner sa clé d'accès GitHub (enregistrée localement dans le navigateur).
3. Choisir une photo depuis la galerie : elle est automatiquement redimensionnée, envoyée dans `assets/chantiers/` et ajoutée à `js/chantiers.js`.
